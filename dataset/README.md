# Dataset

The dataset used in this replication and extension study is not redistributed in this repository.

The original FuseFL artifact, released by the authors of:

Widyasari, R., Ang, J. W., Nguyen, T. G., Sharma, N., & Lo, D. (2024). *Demystifying Faulty Code with LLM: Step-by-Step Reasoning for Explainable Fault Localization.*

is available at:

https://figshare.com/s/bce02cb607a6c30043ad

The artifact contains:

* Faulty code files used in the FuseFL evaluation
* Faulty line explanations
* Prompt templates
* Prompt execution results
* Human evaluation data

To reproduce the experiments reported in this repository:

1. Download the original FuseFL artifact from the link above.
2. Extract the required dataset files.
3. Place the dataset contents in the `dataset/` directory.
4. Execute the scripts provided in the `scripts/` directory.

This repository contains the replication and extension implementation, evaluation scripts, generated results, statistical analyses, and visualization artifacts used in our study.
